# Sources

`manifest.yaml` is a candidate acquisition list, not a declaration that a translation is free to redistribute. Entries remain `verification-required` until an edition-specific rights statement is captured.

Verified texts are ingested through `phronesis sources ingest`. Runtime records and text live under `corpus/` and are ignored by Git by default so external works are not accidentally relicensed or redistributed.

See `docs/source-policy.md` and `schemas/source-record.schema.json`.
