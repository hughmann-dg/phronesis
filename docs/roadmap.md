# Roadmap

## Implemented in 0.1

- Repository policy, licensing, schemas, and docs
- Decision Packet validation and claim separation
- Nine explicit doctrines and reusable skills
- Initial five-school independent Council
- Cross-examination, red team, and concrete arbiter synthesis
- Philosophical-basis output with source locators
- Rights-gated local primary-text retrieval
- Decision journal, outcome review, and aggregate calibration signals
- Historical, business, personal, technical, and strategic benchmark cases

## Next

- Add edition-verified public-domain texts to the corpus manifest and retrieval store
- Implement a structured model-backed `Reasoner` adapter with strict output validation
- Add hybrid semantic and lexical retrieval with page/book/section locators
- Add richer forecast scoring such as Brier scores and assumption-level outcomes
- Add moral constraints and rights review before consequential optimization
- Build an accessible interface for packet intake, disagreement comparison, and philosophical basis expansion
- Expand benchmarks with human rubrics, adversarial packets, and calibration datasets
