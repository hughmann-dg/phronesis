# Book-to-skill method

Use this method when adding or revising a school.

1. Select a rights-verified edition and ingest it without altering the primary text.
2. Retrieve passages around a decision concept and read the surrounding section.
3. Record an extracted principle with source id, locator, interpretation, counterpassages, and limits.
4. Compare principles across the same work and related works; do not promote an isolated phrase into a doctrine.
5. Define primary questions, procedure, evidence preferences, failure modes, blind spots, useful situations, and deferral conditions.
6. Implement or update the school skill and executable doctrine.
7. Test the public counsel contract on cases where the lens should help and cases where it should defer.
8. Review every quotation and doctrinal claim for traceability.
9. Declare any reference knowledge skill on the executable doctrine and route the counsel skill through it.
10. Put school-specific output under `extensions`, then run `phronesis audit --root .`, the full tests, and the benchmark.

Retrieval answers what the source says. The skill defines how the school reasons. Neither substitutes for the other.
