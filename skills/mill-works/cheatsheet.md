# Mill Works — Decision Cheatsheet

## Route First

| Situation | Load | Ask |
|---|---|---|
| “Utility” means convenience | ch03 | Whose happiness and which harms are actually counted? |
| Benefits differ in kind | ch03 | What would informed people acquainted with both value, and why? |
| Good intent is offered as proof | ch03 | What are the act's effects, the motive, and the character signal separately? |
| Compliance is uncertain | ch04 | Which external and internal sanctions support or undermine action? |
| Ultimate value claim is disputed | ch02, ch05 | What kind of proof is possible for the proposed end? |
| Minority bears severe harm | ch06-ch07 | What right, security interest, consent, and alternative are at stake? |

## Decision Rules

- If a stakeholder is absent from the table, add them before aggregating.
- If impacts are incommensurable, show the trade-off rather than hiding it in one score.
- If evidence supports only ranges, preserve ranges and test sensitivity.
- If a severe involuntary harm is concentrated, run rights and justice review before optimization.
- If a rule normally protects trust or security, include the long-run cost of making an exception.

## Attribution Checks

- Mill's 1879 text is not identical to every later form of utilitarianism.
- “Competent judges” is an argument about qualitative preference, not permission for elite fiat.
- Chapter IV's “proof” is philosophically contested; label interpretation as interpretation.
- Do not invent numerical utilities and call them Mill's method.
