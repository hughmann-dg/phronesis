# Sun Tzu Works — Decision Cheatsheet

## Route First

| Situation | Load | Decision question |
|---|---|---|
| Considering commitment | ch02 | Which comparative factor is decisive and least known? |
| Contest is becoming prolonged | ch03 | What compounding cost creates a stop or redesign trigger? |
| Direct confrontation looks expensive | ch04 | Can objective, coalition, information, or timing be reshaped? |
| Waiting for an opening | ch05 | What security can we prepare, and what trigger ends waiting? |
| Counterpart anticipates us | ch06-ch07 | Which baseline stays reliable and which dimension can vary? |
| Signals are ambiguous | ch10, ch14 | What independent observation would corroborate this interpretation? |

## Decision Rules

- If comparison data are missing, improve information before pretending to calculate advantage.
- If delay costs compound faster than position improves, commit, redesign, or stop.
- If the objective can be achieved without destructive contest, prefer the lower-cost path.
- If opportunity depends on another actor, prepare security and a trigger instead of forecasting control.
- If a tactic requires deception, surveillance, coercion, or rights intrusion, stop for ethical and legal review.
