# Reference Unit 2: Price's Letter and Bayes's Problem

## Core Idea

Price introduces the posthumous manuscript and describes its scientific interest; Bayes then states the inverse problem of learning about an unknown event chance from observed occurrences and failures.

## Frameworks Introduced

- **Forward-Inverse Split**: Distinguish predicting outcomes from a known chance and inferring chance from outcomes. (pp. 370-376)
  - When to use: A base-rate problem is described ambiguously.
  - How: State which quantity is known, observed, and sought.
- **Observation-Scope Check**: Define the repeated experiment and what counts as an event or contrary event. (Problem, pp. 375-376)
  - When to use: Historical outcomes are pooled without a sampling model.
  - How: Specify population, window, selection, and changing conditions.
- **Attribution Check**: Label Price's claims about application and merit as Price's framing.

## Key Concepts

- **Unknown chance**: Parameter to be inferred.
- **Observed events**: Reported successes and failures.
- **Converse problem**: Price's description of reversing the usual chance question.
- **Posthumous communication**: Price's role in presenting the paper.

## Anti-patterns

- **Direction confusion**: Treating a forward binomial calculation as the inverse result.
- **Sampling silence**: Ignoring why these observations were seen.
- **Historical priority inflation**: Claiming the paper contains every later Bayesian concept.

## Worked Example

A service has 18 failures in 1,000 requests. Forward analysis asks how likely that count is under a specified failure rate; inverse analysis asks what rates remain plausible given the count and a stated model.

## Key Takeaways

1. Name the direction of inference.
2. Define the event-generating process.
3. Separate Price's framing from Bayes's mathematics.
4. Keep later terminology labeled as later.
