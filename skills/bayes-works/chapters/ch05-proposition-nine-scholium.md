# Reference Unit 5: Proposition 9 and Scholium

## Core Idea

Proposition 9 relates observed counts to the probability that an unknown chance lies between specified bounds; the scholium turns the result into usable rules and approximations.

## Frameworks Introduced

- **Bounded-Chance Update**: Ask how much probability the evidence assigns to an interval of possible chance. (Proposition 9, pp. 395-399)
  - When to use: A point estimate overstates what the data establish.
  - How: Choose decision-relevant bounds, verify the formula, and report interval probability.
- **Approximation Error Check**: Treat Rules 1-3 as approximations with conditions, not exact universal shortcuts. (scholium, pp. 399-418)
  - When to use: Manual or simplified computation is used.
  - How: Verify inputs, assumptions, and error against modern reliable computation.
- **Decision-Relevant Threshold**: Select bounds because they change action, not because they flatter the result. (modern adaptation)

## Key Concepts

- **Proposition 9**: Central inverse-probability statement.
- **Bounds**: Lower and upper possible chance values.
- **Scholium**: Explanatory application following the proposition.
- **Rules 1-3**: Approximation procedures in the later pages.

## Anti-patterns

- **OCR mathematics**: Calculating from corrupted symbols.
- **Point-estimate theatre**: Reporting one precise rate from sparse evidence.
- **Threshold shopping**: Choosing bounds after seeing the answer.

## Worked Example

A safety review asks whether a failure probability is plausibly below a required threshold, not merely what the average estimate is. It pre-registers the threshold, uses a modern verified calculation, and cites Bayes only for historical grounding.

## Key Takeaways

1. Verify Proposition 9 against the scan.
2. Prefer decision-relevant intervals.
3. State approximation conditions.
4. Predefine thresholds when possible.
