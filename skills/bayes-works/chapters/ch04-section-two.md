# Reference Unit 4: Section II — Geometrical Construction

## Core Idea

Section II introduces a physical/geometrical experiment in which an initial random position determines the chance of later events, creating a distribution over the unknown chance that enables inverse calculation.

## Frameworks Introduced

- **Prior-Generating Construction**: Make explicit what process assigns probability across possible chance values. (postulate and experiment, pp. 389-393)
  - When to use: A uniform prior is described as neutral.
  - How: State the parameter, scale, range, and mechanism or convention.
- **Parameterization Sensitivity**: Uniformity in one representation need not remain uniform after transformation. (modern interpretive limit)
  - When to use: “Flat” prior claims objectivity.
  - How: compare reasonable parameterizations and data scales.
- **Model-to-World Bridge**: Separate Bayes's idealized table experiment from the empirical process under study.

## Key Concepts

- **Postulate**: Assumption establishing uniform placement in the construction.
- **First ball**: Position that determines the chance parameter in the experiment.
- **Subsequent balls**: Trials classified relative to the first position.
- **Uniformity**: Property generated by the specific geometry.

## Anti-patterns

- **Ignorance-equals-uniform**: Treating lack of knowledge as a unique distribution.
- **Parameterization blindness**: Ignoring how representation changes prior mass.
- **Analogy substitution**: Assuming a real system shares the table model.

## Worked Example

A defect-rate analysis compares a uniform prior on the rate with an empirically grounded prior from comparable lines. The report names why each is considered and shows how conclusions differ.

## Key Takeaways

1. Record prior provenance.
2. Uniformity needs a specified scale and construction.
3. Test alternative priors.
4. Validate the model-world bridge.
