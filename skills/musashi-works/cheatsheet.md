# Musashi Works — Decision Cheatsheet

## Route First

| Situation | Load | Decision question |
|---|---|---|
| Team understands but cannot execute | ch03 | What representative rehearsal would demonstrate capability? |
| Timing is decisive | ch02, ch04 | What rhythm and observable crossing signal govern commitment? |
| One tool or process is treated as universal | ch02, ch05 | Under what conditions does its advantage reverse? |
| Local urgency hides system effects | ch03 | What changes when we alternate near and wide views? |
| Repeated attempts preserve the same failure | ch04 | Is this a deadlock, and what materially different method follows? |
| Ambiguity is being spiritualized | ch06 | What is observed, inferred, unknown, and testable? |

## Decision Rules

- If competence exists only on paper, rehearse before committing.
- If timing matters, define phases and signals; do not substitute speed for rhythm.
- If a posture or tool is defended as universally best, test the conditions where it fails.
- If a second attempt preserves the same causal mechanism, trigger a material method change.
- If a transition has a costly middle state, define entry, commitment, rollback, and abort conditions.
- If the context is cooperative, reject enemy framing.
- If an application proposes violence, coercion, deception, illegality, or unsafe practice, stop.
