# Plato Works — Decision Cheatsheet

## Route First

| Situation | Load | Ask |
|---|---|---|
| Terms slide during debate | ch02-ch03 | Is this a definition, an example, or an effect? |
| Confidence exceeds support | ch04 | What is known, inferred, and outside competence? |
| Presentation persuades without teaching | ch07 | What could the audience now explain or test? |
| Duty and convenient exception conflict | ch05 | Which principle and relationship create the obligation? |
| Metaphysical claim drives action | ch06, ch09 | What empirical or normative bridge is missing? |

## Decision Rules

- If participants use one term differently, define it before scoring options.
- If questioning produces only confusion, convert the largest unknown into an evidence request or reversible test.
- If authority rests on office or reputation, audit the claim without dismissing demonstrated expertise.
- If a message changes confidence but not competence, classify it as persuasion rather than instruction.
- If a principle demands obedience despite serious injustice or danger, stop and apply rights, legal, and safety review.

## Attribution Checks

- Dialogue speech is not automatically Plato's settled position.
- Jowett's introduction and marginal analysis are not Plato's text.
- Verify Stephanus letters in the rendered edition before quoting.
- Never invent a quotation to make a paraphrased framework sound ancient.
