# Reference Unit 3: Euthyphro

## Core Idea

*Euthyphro* tests successive definitions of piety, exposing answers that give examples, depend on disputed approval, describe an effect instead of an essence, or circle back to what they were meant to explain.

## Frameworks Introduced

- **Example-versus-Definition Gate**: An instance does not yet state the common feature. (*Euthyphro* 5d-6e)
  - When to use: A policy is defended with one vivid case.
  - How: Ask what makes all valid cases members of the same category.
- **Approval Independence Test**: Ask whether approval makes an act good or tracks a reason it is good. (9e-11b)
  - When to use: Authority or popularity is offered as the sole standard.
  - How: Separate the approving source from the property supposedly recognized.
- **Part-Whole and Circularity Check**: Test whether a definition narrows the concept and whether its explanation returns to the starting word. (11e-15c)
  - When to use: Abstract values are defined through near-synonyms.
  - How: Substitute the definition into the claim and see whether it adds independent criteria.

## Key Concepts

- **Piety**: Contested concept at the center of the dialogue.
- **Approval relation**: Whether being approved is cause, effect, or evidence.
- **Circular definition**: Explanation that presupposes what it claims to define.
- **Counterexample**: Case exposing overbreadth or inconsistency.

## Mental Models

- Ask whether a metric creates value or only imperfectly signals it.
- Replace synonym chains with observable decision criteria.

## Anti-patterns

- **Authority-as-definition**: Treating endorsement as the property itself.
- **Metric worship**: Assuming a score constitutes the value it measures.
- **Infinite clarification**: Refusing an adequate operational definition because no essence is settled.

## Worked Example

An organization defines “fair” as “approved by the compensation committee.” The approval-independence test asks what criteria the committee is meant to recognize—comparable responsibility, transparent bands, remedy of bias—and allows those criteria to be evaluated directly.

## Key Takeaways

1. Separate examples from definitions.
2. Separate approval from grounds.
3. Test definitions by substitution and counterexample.
4. Stop when an operational definition is decision-sufficient.
